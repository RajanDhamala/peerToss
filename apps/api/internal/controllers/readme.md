# ZRP routing protocol

1) most important example of hybrid routing is ZRP (Zone Routing Protocol).

  ZRP divdes the MANET into routing zones.Each node has it's own zone based on a predefined zone radius.

# How hybrid Routing works?

Step 1 :Divide network into zones 
        each node cosider a gorup of nearby nodes as its routing zone.

Step 2 :Maintain local route 
        routes within the local zone are maintianed proactively so the node already knows how to reach the nearby nodes.


Step 3 :Search for distant node
        Search for a distant nodes  when required if the destination is outside the local zone the node starts the on demand
        route discovery process.
Step 4 : Establish the route
        once the destination is found the data can be transmitted through the discovery path
